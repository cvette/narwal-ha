# Logo

`icon.svg` is the source of the integration's icon: a robot vacuum seen from
above (bumper arc and laser turret) above two linked nodes, for control over
the local network. It is original artwork made for this project from basic
shapes, under the repository's MIT licence. It uses no Narwal or Home
Assistant marks, and it is not an official Narwal logo.

The PNGs Home Assistant shows (2026.3 and later) live in
`custom_components/narwal_local/brand/`: `icon.png` (256 × 256) and
`icon@2x.png` (512 × 512), transparent and trimmed to the circle. To rebuild
them, render `icon.svg` at both sizes with a transparent background, for
example in a headless browser, and save them as optimized PNGs.

Colours: `#14b8a6` → `#0f766e` (body gradient), `#5eead4` (link), white.

`social-preview.png` (1280 × 640) is the card GitHub shows when the
repository is shared; it is uploaded under the repository's Settings →
General → Social preview. Its source is `social-preview.html`: render it at
exactly 1280 × 640, for example with a headless browser.
